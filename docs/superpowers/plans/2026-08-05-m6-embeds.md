# M6 — Embeds: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Editors can place a guided tour on any existing page — as a Portable Text block or a page-builder section — via a `guidedTourEmbed` object, a dereferencing projection fragment, and a ready-made `<GuidedTourEmbed>` renderer (issue #109).

**Architecture:** Three thin layers matching the plugin's existing seams: schema object (Studio entry), projection + types (`/queries`, dependency-free), renderer (`/react`, client). Consumers wire the object into their own arrays (`{type: 'guidedTourEmbed'}`) and map the type in their PT/section renderers.

All M1–M5 constraints hold (memory `guided-tours-m1-execution-facts`): entry isolation, `use client` banner (react entry only — new react files need the directive), coalesce policy for initialValue-bearing fields, no `as` casts, PR flow with review threads, oxlint/oxfmt, 1-decimal invariants n/a here. ### Task 2: Projection + types

**Files:** Modify `src/queries/projections.ts` (add + export `guidedTourEmbedProjection`), `src/queries/index.ts` (re-export), `src/queries/types.ts` (`GuidedTourEmbedValue`); Test extend `test/queries.test.ts` + `test/queries.groq.test.ts`

```groq
export const guidedTourEmbedProjection = /* groq */ `{
  _key, _type,
  "displayMode": coalesce(displayMode, "${EMBED_DEFAULTS.displayMode}"),
  buttonLabel,
  "tour": tour->${tourProjection}
}`
```

The `"inline"` fallback is NOT hardcoded: add `EMBED_DEFAULTS = {displayMode: 'inline'}` to `src/queries/defaults.ts` (the single source of truth for schema initialValues used by coalesces) and consume it in both the schema's `initialValue` and this projection — same pattern as every existing coalesce.

Type: `{_key: string; _type: 'guidedTourEmbed'; displayMode: 'inline' | 'modal'; buttonLabel: string | null; tour: GuidedTourDoc | null}` — `tour` nullable (broken/unpublished/draft-only reference dereferences to null; the coalesce policy applies to `displayMode` since it carries an initialValue).

TDD: string assertions; groq-js evaluation — an embed inside a fixture page document: full deref (tour fields resolved through tourProjection incl. its own coalesces), null-ref case, missing displayMode coalesces to inline. `@public` tags for api-extractor.
